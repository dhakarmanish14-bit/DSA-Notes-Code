# DSA Notes & Code

This repository contains my **Data Structures and Algorithms (DSA) notes, implementations, and practice code** written while learning and strengthening my DSA fundamentals.

The main goal of this repository is to understand how data structures and algorithms work internally by implementing them from scratch and practicing their use in problems.

  * Binary Search Tree
* Sorting
  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Merge Sort
  * Quick Sort
  * Counting Sort
* Linked Lists
  * Singly Linked List
  * Doubly Linked List
  * Circular Linked List
  * Linked List Insertion & Deletion
* Stacks
  * Stack using Array
  * Stack using Linked List
  * Parenthesis Matching
  * Infix to Prefix
* Queues
  * Queue using Array
  * Queue using Linked List
  * Circular Queue
* Trees
  * Binary Tree Traversals
  * Binary Search Tree
  * BST Insertion
  * BST Deletion
  * AVL Tree
* Heaps
  * Min Heap
  * Max Heap
* Graphs
  * BFS Traversal
  * DFS Traversal
* Hashing
  * unordered_map implementation
  * using Open Addressing
  * using Separate Chaining
